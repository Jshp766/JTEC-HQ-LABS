# GitHub Evidence Checklist — Labs 02–10

For each lab, add the following where available.

## Required

- [ ] README.md
- [ ] Packet Tracer `.pkt` file
- [ ] Clean topology screenshot
- [ ] 2–5 meaningful CLI screenshots
- [ ] Configuration text where useful
- [ ] Verification evidence
- [ ] Troubleshooting evidence for labs containing faults

## Screenshot naming

Use:

```text
01-topology.png
02-configuration.png
03-verification.png
04-troubleshooting.png
05-final-test.png
```

Do not upload dozens of screenshots with no explanation.

## What makes evidence useful?

A screenshot should prove something.

Good examples:

- `show vlan brief` proving VLAN membership
- `show interfaces trunk` proving trunk operation
- `show etherchannel summary` proving LACP state
- `show spanning-tree vlan 20` showing STP path selection
- successful ping proving end-to-end connectivity

## Before uploading

Check every screenshot for:

- Real passwords
- Enable secrets
- Private employer information
- Unnecessary personal information
- Unclear/cropped command output

Redact credentials before committing.
