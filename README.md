# JTEC Network Engineering Lab Portfolio

## About This Project

This repository documents my hands-on networking lab environment,
built using Cisco Packet Tracer while developing my networking and
troubleshooting skills.

This project is my journey into networking starting with the fundamentals
and then more advanced subjects like automation and security.

Rather than focusing only on device configuration, each lab follows
a structured engineering workflow:

Plan → Configure → Verify → Troubleshoot → Document

## Troubleshooting Methodology

My general troubleshooting workflow is:

1. Identify the reported problem.
2. Establish the affected devices/users.
3. Check physical and interface state.
4. Verify Layer 2 configuration.
5. Verify Layer 3 addressing and routing.
6. Compare expected and actual configuration.
7. Identify the root cause.
8. Implement the fix.
9. Verify connectivity.
10. Document the incident and resolution.
